# 设计来源与适配边界

来源：Felix Rieseberg，[How to be more ambitious: A tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/)，发布于2026-10-13；本会话于2026-10-17读取原文。

原文将AI使用的进取方向分为速度、高度、深度和广度，重点讨论后三项，并强调真实工具、原始材料及外部验证。本技能以自己的文字将这些建议转成工作指导，不复制文章全文。

“高度 → 广度 → 深度 → 验证”是本会话与用户讨论后形成的执行顺序，原文没有规定这条流水线。将广度放在深度之前，是为了先选择方法，再投入执行；把验证独立列出，是为了明确证据标准和回退依据。

适配中加入了任务规模判断、保持原交付物、约束内执行和有证据才回退的规则。文章中关于大胆设定目标的建议，在这里落实为挑战目标加测量与有限可行性探查；信心不作为结果正确或目标可达的证据。

本技能不依赖某个模型品牌、特定连接器、固定专业软件或其他已安装技能。可用工具和材料以运行时环境为准。

专家工具是原文深度维度的明确要求：需要采用专业人士实际使用的工具和方法，而不仅仅改变措辞。本技能将其落实为工具识别、可用性检查、实际执行、反馈处理和可检查产物；方法库中的工具为方法示例，具体选择由任务需要决定。

本技能还采用了原文中的紧迫决策与正反理由、用原始数据挑战假设、发现新知识并在未见数据验证、深化任务的四个问题与提示词改写、将名词转成行动、召集互补专长等方法，分别并入高度、广度和深度。按数据条件决定是否仿真、预留独立验证材料及保持原交付物，是为可执行与证据可靠性所作的适配。

原文是方法灵感，不构成本技能提升效果的实验证据。少量成对任务只能描述本轮行为；自动触发、跨任务稳定性和长期收益需另外验证。

投入判断优先于方法选择：默认直接完成，具体缺口才局部深化，明确的探索目标才进入深入方法。原文建议构成按需方法库，不是每项任务的必做清单；达到用户所需程度后停止。此为用户明确要求的适用范围与成本控制。

本候选版将原通用深化框架调整为科研选题用途；保留目标约束、实际证据、反例和投入判断。改造依据包括用户明确提供的需求、图片及相关对话反馈；候选版的行为效果以实际评测为准。
