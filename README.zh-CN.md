# Research Idea Lab 科研选题与跨领域探索

[English](README.md) | **简体中文**

Research Idea Lab 是一个帮助研究者探索、发展和审视科研 idea 的 Codex 技能。它适应不同研究阶段：探索新方向、发展已有想法，或在投入资源前审查方案。

它适用于多个研究阶段：进入陌生领域、评估已有想法，或判断其他领域的方法能否迁移到当前问题。

## 能做什么

- **明确问题**：梳理目标任务、实际困难、影响对象和问题成立的条件。
- **核查相关工作**：围绕研究问题、输入、机制、监督、假设和评价比较最近邻，主动寻找直接先例和反例。
- **从近期论文出发**：调研代表性工作，核查开源起点，跨论文比较尚未解决的困难，再收敛研究问题与 idea。
- **探索候选方向**：提出少量可发展的想法，说明预期价值、核心假设与代价；在有帮助时探索跨领域迁移。
- **发展完整方案**：提出逻辑连贯的方法及关键假设，允许尚未验证的机制和相互配合的模块作为研究设想。
- **建设性地比较和审查**：区分问题、组件复用和完整方法的重合；分析具体先例、可能的改进和关键质疑，不仅因组合已有技术就否定方案。
- **设计可证伪的下一步**：提出与当前阶段相称的比较、所需证据和资源，以及什么结果会削弱或改变判断。

技能会区分论文报告的证据、解释、研究假设和说明性例子；它不能保证 idea 首创、论文发表或实验成功。文献检索能力取决于当前会话可用的工具和访问条件。

## 在 Codex 中安装

将仓库克隆到个人 Codex 技能目录：

```bash
git clone https://github.com/shepherd0106/research-idea-lab.git ~/.codex/skills/research-idea-lab
```

仅在 `~/.codex/skills/research-idea-lab` 不存在时使用此命令。如果已经安装，请先检查并更新原目录，避免覆盖已有修改。若技能没有立即出现，可以开启一个新的 Codex 会话。

## 使用示例

在 Codex 对话中显式调用：

```text
$research-idea-lab 我正在探索［研究领域］。请帮我确定一个具体、可验证的
研究问题，比较最接近的工作，并评估一个值得继续的方向。
我的资源和约束是：［具体信息或暂不确定］。
```

也可以用它审查已有想法：

```text
$research-idea-lab 请比较这个 idea 和最接近的研究，说明完整方案可能
带来什么价值，并从审稿人角度提出具体质疑与需要补充的证据。
```

或者探索跨领域迁移：

```text
$research-idea-lab 我想把［来源方法］用于［目标问题］。请对应两边的
变量和成立条件，查找相关先例，并判断它是否解决了有价值的实际困难。
```

提供任务、相关论文或链接、数据、算力、研究阶段和明确约束，有助于得到更具体的判断。暂不清楚的资源可以标为“未知”，不需要提前假设。

## 仓库结构

```text
research-idea-lab/
├── SKILL.md                     技能入口与工作流程
├── agents/openai.yaml           Codex 界面配置
└── references/
    ├── novelty-and-evaluation.md
    ├── paper-grounded-ideation.md
    ├── research-transfer.md
    ├── reviewer-stress-test.md
    ├── source.md
    └── techniques.md
```

技能会根据任务按需读取参考资料。它主要用于科研选题和想法评估；已确定方法的常规实现、普通翻译或单独的论文讲解可使用更合适的工作流。

## 使用边界

评估结果取决于当时可访问的文献、检索范围和现有证据质量。请将输出作为继续研究的起点，并结合领域知识与实验核验；它不能替代新颖性证明。
